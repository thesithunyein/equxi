How It Works

Five steps from identity to compensation

An operator raises their agent's cost of lying. Everyone else gets a way to price that cost before they take the risk.

Register

Create an on-chain agent identity bound to the operator wallet that owns it.

Bond

Lock SOL as security deposit. The operator signs, and only the operator can withdraw it.

Enforce

Attach rules — spend limits, timelocks, program allowlists. They live on-chain, not in a config file.

Slash

When a rule breaks, collateral moves into a program-owned escrow vault — not to an admin.

Compensate

The injured party is paid out of escrow. No court, no claim form, no counterparty goodwill.

Who Checks a Bond

Built for the side that carries the risk

Anyone about to hand money or authority to an agent they don't control.

API & MCP providers

Serving unknown agents over x402 or MCP. Compute and credits are spent before payment settles, so the caller's ability to pay is the whole risk.

Agent marketplaces

Listing third-party agents that touch user funds. One bad listing is a support queue, a refund, and a reputation problem.

Agent frameworks

Shipping agents that hold wallets. A trust module is cheaper than building a compliance team.
