Trust Explorer

One question matters when an autonomous agent holds your money: does it have collateral at risk, and has it ever been slashed? Every number on this page is read from the Equxi program on Solana — nothing here is self-reported by the agent.

How the grade is computed. The score is derived from observable on-chain evidence only: whether a bond is posted and how large it is, and whether each recorded violation has actually been compensated to a victim. It deliberately ignores the on-chain trust_score field, which is set by the program admin and is therefore an assertion rather than evidence. An agent with no bond is reported as ungraded — not as trustworthy.
Data comes from GET /api/trust over the devnet cluster. The source for this page is api/trust.js and lib/equxi-layout.js, with the scoring rules pinned by tests in tests/unit/api.test.ts.
