Trust Explorer

One question matters when an autonomous agent holds your money: does it have collateral at risk, and has it ever been slashed? Every number on this page is read from the Equxi program on Solana — nothing here is self-reported by the agent, and every grade comes with the deductions that produced it.

How the grade is computed. The score is derived from observable on-chain evidence only: whether a bond is posted and how large it is, and whether each recorded violation has actually been compensated to a victim. Each agent's detail panel lists the deductions as a ledger that sums to the score, so the number can be checked rather than trusted. It deliberately ignores the on-chain trust_score field, which is set by the program admin and is therefore an assertion rather than evidence. An agent with no bond is reported as ungraded — not as trustworthy.
Embed a live grade. Any agent can wear its own badge: GET /api/badge?agent=<pda> returns an SVG that re-reads the chain on every request (add &format=json for the numbers). A badge is a live view, not a certificate.
Data comes from GET /api/trust over the devnet cluster. The source for this page is api/trust.js, api/badge.js and lib/equxi-layout.js, with the scoring rules pinned by tests in tests/unit/api.test.ts.

Get an agent listed. A registry entry is not something you apply for, and nothing on this page is self-reported: connect a wallet in the dashboard, register the agent, then lock a bond. The bond is the collateral that gives the grade something to be about — an agent with no bond still appears here, marked ungraded, because presence is not a claim of trustworthiness.
