The Idea

A launch that creates its own consequence

The same transaction trail that creates the token creates the collateral.

Launch on DBC

The token discovers its price on Meteora's Dynamic Bonding Curve. The config routes 50% of trading fees — and half of the 10% migration fee — back to the launch.

Graduate into DAMM v2

The final buy is a partial fill, so the curve stops exactly at the threshold and graduates into permanent liquidity instead of overshooting.

Post it as a bond

The claimed proceeds become the launched agent's Equxi bond — slashable collateral, with the bond's ledger, lock and unbonding window all enforced on chain.

    What this does not prove

    Stated here so nobody has to discover it from the chain.

    Devnet, not mainnet

    Every transaction ran on devnet. Meteora's production migration keepers run on mainnet, so here the migration was executed manually — the step is linked above.

    0.0698 + 0.0302

    The launch's claimed proceeds were 0.0698 SOL; Equxi's minimum bond is 0.1 SOL, so the remaining 0.0302 SOL is a disclosed top-up, not launch proceeds.

    0.0056 SOL left unclaimed

    Trading fees must be claimed before migration — after migrate_to_damm_v2 the fee vaults are gone. This run learned that too late; the README says so.
