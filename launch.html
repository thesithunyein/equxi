How It Works

A launch that creates its own consequence

The same transaction trail that creates the token creates the collateral.

01

Launch on DBC

The token prices itself on Meteora's curve. Half the trading fees, and half the 10% migration fee, route back to the launch.

02

Graduate into DAMM v2

The final buy is a partial fill: the curve stops exactly at graduation and moves into permanent liquidity instead of overshooting.

03

Post it as a bond

The claimed proceeds become the agent's bond — slashable collateral, with the ledger, lock and unbonding window enforced on chain.

    Limits

    What this run does not prove

    Next to the proof, not buried on-chain.

    01

    Devnet, not mainnet

    Every transaction ran on devnet. Meteora's migration keepers only run on mainnet, so this migration was run manually — signature linked above.

    02

    0.0698 + 0.0302 SOL

    The launch claimed 0.0698 SOL in proceeds. Equxi's minimum bond is 0.1 SOL, so the remaining 0.0302 SOL is a disclosed top-up, not launch proceeds.

    03

    0.0056 SOL left unclaimed

    Trading fees must be claimed before migration — migrate_to_damm_v2 takes the fee vaults with it. This run learned that too late. So does the README.
