01
The Problem

AI agents handle money.
Nobody can trust them.

Counterparties refuse to deal with agents that can lose funds with no recourse. Traditional wallets only hold money — they cannot enforce behavioral rules or compensate victims.

No Accountability

AI agents execute transactions autonomously. When they misbehave, there is no mechanism to penalize them or compensate victims.

No Trust Layer

Existing wallets hold funds but cannot enforce spending limits, timelocks, or program allowlists on-agent behavior.

02
The Solution

Bond. Enforce. Slash.

Equxi is a Solana program that makes AI agents financially accountable. Operators lock SOL as a bond, set on-chain rules, and get slashed when agents misbehave.

03
On-Chain Infrastructure

8 instructions. All verified.

  • Register Agent — create on-chain identity with operator wallet
  • Create Bond — lock SOL as security deposit
  • Add Constraint — set spend limits, timelocks, program allowlists
  • Execute Slash — penalize bond when rules are violated
  • Compensate — distribute slashed funds to victims
  • Withdraw — return bond when agent is decommissioned
  • Trust Score — calculate reputation from on-chain history
  • Initialize — deploy program config

05
Open Source

Fully open. MIT license.

The entire codebase is public. Solana program, TypeScript SDK, elizaOS plugin, dashboard. Anyone can fork, audit, and build on it.

Why Open Source Matters

Closed trust layers can be revoked, surveilled, or priced out of reach. Open-source accountability infrastructure belongs to everyone — especially developers in underserved markets who cannot afford proprietary alternatives.

What Happens If It Closes

AI agent builders lose the only open accountability layer on Solana. They must build from scratch or depend on centralized solutions that can be switched off overnight.
