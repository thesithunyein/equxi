01
The Problem

Agents are being handed money. Nobody can check them.

The rails already exist — agents have wallets, cards, bank accounts and paid API access. None of it answers what happens when an agent takes the payment and doesn't deliver.

The provider eats the loss

An API or MCP endpoint serving an unknown agent spends compute and credits before settlement clears. If the agent never pays, there is no recourse but to block the address.

A score with nothing behind it

Reputation that costs nothing to lose is free to lie. An agent can burn a rating, re-register under a new key, and be back to a clean slate the same block.

Permission is solved. Consequence isn't.

Wallets cap what an agent can spend and allowlists cap where. Nothing makes it pay when it breaks a rule anyway.

No compensation path

When an agent rugs a counterparty there is no on-chain mechanism to make the injured party whole. The loss is final.

02
The Solution

Bond. Enforce. Slash. Compensate.

An operator registers an agent and locks SOL as a bond. The program holds it in its own vault. Rules run on-chain, and any counterparty can read the bond and the slash history from one endpoint before deciding whether to deal.

05
Market

Who pays, and why now

Three buyers, one primitive. Each is already handling agents it cannot verify.

API & MCP providers

Agents call paid endpoints directly over x402 and MCP. Compute and credits are spent before settlement clears, so the caller's ability to pay is the entire risk. Equxi turns it into a bond a provider can read in one request.

Agent marketplaces

Marketplaces listing third-party agents need to gate the ones touching user funds. A required bond moves liability off the platform and onto the operator who built the agent.

Agent frameworks

Frameworks shipping wallet-holding agents need a trust module, not a compliance team. One import gives their agents a bond and their users a way to check it.

Agent-to-agent commerce

When two agents transact unsupervised, neither can sue the other. Collateral is the only recourse that settles in the same block as the breach.

06
Why Now

The rails are funded. The safety layer isn't.

Colosseum's own portfolio is building the agent economy's payment and access layer. None of it is the part that makes an unknown agent safe to deal with.

Already funded

Laso gives agents cards and bank accounts. Frames lets agents pay for resources. Clawpump gives agents companies. Flovia measures agent payments. Sudont secures agent execution. MCPay and Corbits won track prizes for x402 rails.

The gap

Every one of them assumes the counterparty is good for the money. Nothing on the stack answers what happens when an agent takes payment and doesn't deliver — the exact question a provider asks before serving it.

Why Solana

This is only cheap where breach and payout land in the same block. Bond, rule evaluation, seizure and compensation are one program with no oracle in the loop.

Timing

Agent payment volume is the fastest-growing new counterparty class on Solana, and every provider onboarding to it rediscovers this problem from scratch.

07
Open Source

Public code. Permanent trust.

The entire codebase is MIT licensed — program, SDK, plugin, dashboard and read API. Anyone can fork it, audit it, or run their own registry without asking permission.

Why This Matters

Closed trust layers can be revoked, surveilled, or priced out of reach. Accountability infrastructure must be open to be trusted. Developers in underserved markets need access to the same tools as everyone else.

What Happens If It Disappears

Agent builders lose the only open accountability layer on Solana. They must build from scratch or depend on centralized alternatives that can be switched off overnight.

Business Model

We charge for the check, and the bond.

Reading a bond is free and stays free — a trust layer nobody queries has no value. Revenue sits on the two sides that care about the answer.

  • Take rate on bonded volume. A basis-point fee when collateral is posted, and again when it is slashed. Revenue scales with how much risk the network is actually underwriting — not with how many people sign up.
  • Verification API. The public badge stays free forever. Providers that need threshold checks, webhooks or volume get a paid tier — the same shape as any risk-data API.
  • Marketplace gating. Platforms that require bonding for listed agents pay per listing. They move liability onto the operator; we get distribution into every agent they onboard.
  • What we want: devnet to mainnet with an audit, and our first ten external operators bonded. Verdicts are admin-gated today — deliberately, at this stage. Decentralising that is the roadmap, and the first thing we would fund.
